ELEMENT DECOMPOSITION DEMO — Primitive geometry for object templates
═══════════════════════════════════════════════════════════════════════

INSTRUCTIONS

You are given an object template's semantic description. Produce a
compact decomposition of the object into primitive elements that
approximates its shape. This decomposition is stored in the element
registry and reused across all future memories that involve the same
template.

Coordinate convention:
    - Z is up (right-handed).
    - The ground is at z=0.
    - Lengths are in centimetres.
    - Each element's transform positions the element relative to the
      object's local origin (its centroid), not relative to world.
    - Rotations are quaternions [x, y, z, w].

Available element types and their required parameters:

    sphere       radius_cm
    ellipsoid    radius_x_cm, radius_y_cm, radius_z_cm
    box          size_x_cm, size_y_cm, size_z_cm
    cylinder     radius_cm, height_cm
    cone         radius_cm, height_cm
    torus        major_radius_cm, minor_radius_cm
    capsule      radius_cm, height_cm
    plane        size_x_cm, size_y_cm       (both optional)
    sheet        size_x_cm, size_y_cm, thickness_cm
    wedge        size_x_cm, size_y_cm, size_z_cm
    prism        size_x_cm, size_y_cm, num_sides
    pyramid      base_size_x_cm, base_size_y_cm, height_cm
    hemisphere   radius_cm
    frustum      bottom_radius_cm, top_radius_cm, height_cm

Element transform (optional, identity if omitted):
    {"translate": [x, y, z], "rotate": [x, y, z, w], "scale": [sx, sy, sz]}

Guidelines:

- Keep decompositions compact. 1 to 6 elements per object.
- Use a single primitive when it captures the shape well (a ball is
  a sphere; a board is a box; a rope is a capsule).
- Compose when needed (an apple is a sphere, a short cylinder for the
  stem, and a torus for the calyx).
- Do NOT model surface details, textures, or internal structure
  beyond what is needed for the object's overall geometry.
- Do NOT model parts that are separate objects in the memory. If an
  apple's flesh is its own template, do not add flesh as an element
  of the apple.
- Provide a plausible default material dict, mass in grams, and a
  short notes string.

Output format (exact):

{
  "elements": [
    {"element_type": "...", "parameters": {...}, "transform": {...}},
    ...
  ],
  "default_material": {"color": "...", "roughness": 0.0-1.0, "metalness": 0.0-1.0},
  "default_mass_grams": <number>,
  "notes": "..."
}

Only the JSON. No commentary, no markdown fences.


═══════════════════════════════════════════════════════════════════════
EXAMPLE 1 — Simple single-primitive decomposition
Object: ball
Context: {dimensions: 8cm diameter, shape: spherical, materials: rubber}
═══════════════════════════════════════════════════════════════════════

{
  "elements": [
    {"element_type": "sphere",
     "parameters": {"radius_cm": 4.0},
     "transform": {"translate": [0, 0, 0], "rotate": [0, 0, 0, 1], "scale": [1, 1, 1]}}
  ],
  "default_material": {"color": "red", "roughness": 0.5, "metalness": 0.0},
  "default_mass_grams": 150.0,
  "notes": "A rubber ball. Single sphere captures the shape."
}

EXAMPLE 2 — Compound decomposition with attached parts
Object: apple
Context: {dimensions: 8cm, shape: spherical, materials: apple_skin,
          apple_flesh, apple_core}
═══════════════════════════════════════════════════════════════════════

{
  "elements": [
    {"element_type": "sphere",
     "parameters": {"radius_cm": 4.0},
     "transform": {"translate": [0, 0, 0], "rotate": [0, 0, 0, 1], "scale": [1, 1, 1]},
     "material_override": {"label": "skin"}},
    {"element_type": "cylinder",
     "parameters": {"radius_cm": 0.15, "height_cm": 1.6},
     "transform": {"translate": [0, 0, 4.2], "rotate": [0, 0, 0, 1], "scale": [1, 1, 1]},
     "material_override": {"label": "stem"}},
    {"element_type": "torus",
     "parameters": {"major_radius_cm": 1.0, "minor_radius_cm": 0.25},
     "transform": {"translate": [0, 0, -3.85], "rotate": [0.7071, 0, 0, 0.7071], "scale": [1, 1, 1]},
     "material_override": {"label": "calyx"}}
  ],
  "default_material": {"color": "red_brushed", "roughness": 0.4, "metalness": 0.0},
  "default_mass_grams": 200.0,
  "notes": "Sphere for the body, cylinder for the stem, torus for the calyx. Skin, flesh, and core are separate templates and are not decomposed here."
}
