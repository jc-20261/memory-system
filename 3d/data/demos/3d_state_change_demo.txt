## Annotation legend

- **P** = preconditions that must hold before the action starts.
- **Δ** = resulting state/attribute changes.
- **Δcyc** = per-cycle changes for cyclical/repeated actions.
- **Δtot** = cumulative/total changes for cyclical/repeated actions.
- **S** = sensory perception changes for the protagonist, each with `src=`.
- **N** = directly linked natural/material process and attribute-aspect changes.
- **Cond** = conditional_changes / variable effects.
- Aspect notation: `object.aspect.attribute`, e.g. `apple.surface.temperature`, `apple.flesh.exposed.color`, `knife.edge.depth`, `hand.palm.residue`.

## Global preconditions inherited unless overridden

Actor: awake, conscious, two functional hands, intact vision, touch, proprioception, olfaction, audition, grip strength, motor control, safe cutting intent.  
Environment: kitchen counter with bowl, cold Honeycrisp apple, running-water tap, shirt/fabric, stable cutting board, paring knife, sink, clean bowl, compost crock.  
Object: intact Honeycrisp apple, cold from refrigerator, dense/turgid, waxy skin, stem/calyx present, no rot.  
Tool: paring knife, short blade, handle worn pale at rivets, sharp enough to cut apple skin.  
Safety: no interruption, no slippage, blade controlled, fingers curled back during pinning.
